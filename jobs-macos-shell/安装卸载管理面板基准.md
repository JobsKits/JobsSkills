## 🔥 <span id="前言">前言</span>

本基准由 Jobs 已确认的安装／卸载面板需求蒸馏，适用于新建及维护同类 GUI。先读取项目现有资产盘点，再按本基准补齐；用户指定的平台、框架及明确例外优先。纯 CLI 不因此新增 GUI；不把样板中的功能数量、Flutter 分组、路径、控件尺寸、颜色十六进制值或某次验证计数复制为所有项目的常量。

## 一、<span id="selection-layout">选择与布局</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- 安装／更新与卸载共用稳定功能 ID 和清单，默认空选，空选不能执行。支持单项、多项及全局全选／全不选；有业务分组时提供组内操作且只影响本组，不为少量无分组功能强造分组。切换操作、主题、语言及布局保留同一会话勾选；不把“显示选中”误当实际执行计划。
- **功能整行可切换勾选**：复选框、标题、图标、普通状态区及行内空白是同一选择入口，完整单击只触发一次。沿用原复选框的状态、动作、键盘 Tab／Space 和无障碍语义；不要叠加父级点击导致一次输入切换两次，也不能只扩大视觉背景却仍要求点小方框。
- 失败日志链接、独立按钮、输入控件等保留自己的动作优先级，点击它们不顺带勾选。分组标题拖动、滚动条、行外空白、组间间隔和其它分组不是行选择区域。按当前实际布局命中，不能使用过期固定坐标或把整组背景映射到一个功能。
- 使用按下—移动—抬起的等价点击语义：在同一行抬起才提交，超过平台拖动容差、离开、滚动或手势时取消待点击，不更改原生滚动方向、精确位移或动量。执行中整行与复选框一起锁定，按下和提交均复核；需要读取的日志动作仍可用。
- 功能列表可滚动，底部操作和结果区保持可达；日志独立滚动，上下分隔可拖动调整。多分组按屏宽自适应列数，状态图标／spinner 共用固定列，状态文字跨组对齐；用最长翻译及长耗时测宽，不靠截断或过小字体隐藏问题。
- 多分组需要重排时，以标题／抓手启动整组拖动，支持排序及跨列移动，保留插入反馈、必要的当前组上下文和边缘滚动；布局按稳定组 ID 持久化。窄屏临时单列不覆盖保存的多列布局，不因拖动重建任务或清空状态。

## 二、<span id="execution-contract">执行与结果</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- 主按钮是当前计划的最终确认，点击后由后台任务执行并回传进度，不再追加重复终端确认；业务工具自身已有的危险确认保留。启动器只唤起 GUI 后结束，不保留无用途终端，不关闭用户已有 Shell。
- 已确认任务的必要依赖健康检查未通过时，按主规则的[条件式自愈](./SKILL.md#dependency-self-healing)与[持续自动获取](./SKILL.md#sdk-acquisition-retry)在原流程中处理；界面显示真实的失败层、修复／重试进度与取消状态，不把首次探测失败直接当作最终结果。
- 以稳定 ID 绑定计划、状态与结果，逐项区分等待、执行、成功、失败、未安装无需卸载及未执行；执行状态用活动指示，不伪造内部构建百分比。总百分比按已处理项目计算，100% 表示处理完毕，不代表全部成功；无需卸载和跳过不冒充实际删除成功。
- 安装／更新、卸载及独立清理分别计时，开始只清零当前操作，每秒更新实际单调耗时，任务进程结束且输出排空后才冻结；同窗切换显示各自已有时长。执行时锁定计划修改和重复执行，结束保留汇总与日志，允许再次操作。
- 功能叶子与安装单元分开：多个已选功能共用一个工程／包时只构建部署一次，安装保留未选的已有功能，卸载只减所选功能，最后一个已启用叶子才移除共享单元。显式“替换全部配置”是独立模式，不由默认空选隐式触发。
- 失败必须来自真实退出码、状态事件及核验结果，不能只看出现成功字符串。单元失败保留其它有效结果；权限、归属、目标路径等阻断按现有事务边界停止后续，不伪造成功或自动绕过许可。界面只提供可核实的设置／恢复入口。
- 提供停止安装时采用协作请求，在当前安全单元完成后停止后续；未执行项单列，不算已失败或成功。不把隐藏窗口、停计时器或关闭输出管道当作停止，不按进程名称强杀共享工具或用户任务。

## 三、<span id="theme-language-logs">主题、语言与日志</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- 提供白天／黑夜／跟随系统，以及简体中文、繁体中文、藏文、英文、日文、法文、西班牙文、德文、俄罗斯文、韩文与跟随系统。偏好入口紧凑、可辨识，保存当前用户设置；弹窗、状态栏／托盘菜单、动态计数、状态、提示及无障碍名称均覆盖。品牌、真实文件名／路径及后台原文保留，不能机械翻译诊断证据。
- 日志有两套完整的背景／前景配色：白天浅底深字，黑夜深底浅字；正文、提示、成功、警告、错误及阶段标题清晰区分，文字／背景对比至少 4.5:1。切换主题、系统外观或高对比度时，已有文本与新输出同轮适配；保留原文、选区、浏览位置及任务，不能只给后来追加的日志换色。
- 结构化状态决定最终成功／失败／停止的颜色，不依赖翻译后的文案猜测；“失败 0”不误标错误，标准编译警告不能仅因来自 stderr 就变成失败。ANSI 等终端样式只在显示层安全处理，复制和文件日志保持纯文本。
- 窗口显示有合理上限，完整会话输出独立落盘，带当前任务的“日志文件”和“复制日志”入口。说明复制的是显示区还是全文；失败项可打开本次完整日志，路径安全引用，正文只作数据显示，不能把日志当命令重新执行。
- 自动追尾初始开启；触摸板、滚轮、滚动条及导航键手动浏览会暂停，重新勾选后跳到末尾并恢复。其它列表滚动不改变日志追尾。调用原生滚动链保留精确位移、动量和横向滚动，追加／预览输出不把已暂停的视口拉回底部。

## 四、<span id="background-lifecycle">关闭与后台生命周期</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- **仅空闲关闭时询问**退到后台还是完全退出，默认后台，取消／Esc 保留窗口；不持久化为以后自动退出。任务执行中关闭不询问，直接挂到 macOS 状态栏／Windows 托盘，任务完成后继续驻留供查看，不自动抢前台。
- 窗口关闭按钮、窗口系统菜单关闭、Cmd+Q／应用正常退出请求等入口共用保护。托盘提供当前状态、恢复原窗口及空闲完全退出；忙时禁用退出，动作实际执行时仍复核。异步选择框使用请求身份防旧回调误消费新选择，等待用户选择期间若任务开始，以任务保全为先。
- 后台只隐藏视图，保留控制器、原窗口、消息循环、worker、输出管道、日志与计时；进程尚未退出、输出未排空或状态未知都不能当作空闲。恢复不重建窗口、不重新开始任务、不丢勾选和浏览状态；显式空闲退出才释放状态项／托盘、计时器、窗口及自有资源。
- 平台实现按实际生命周期验证：AppKit 强持有状态项并绑定应用退出委托，从异步回调停止循环时补唤醒事件；WinForms 隐藏不能让模态调用返回并进入 finally 提前 Dispose，托盘回调要保留所属模块上下文。克隆图标／字体明确释放归属，不能销毁共享资源；兼容旧框架的托盘文字长度限制并保全 Unicode 代理对。
- 区分完整管理面板与只返回计划的内部选择器。已有 stdout／Tag／退出码合同必须保留，不能让等待返回值的调用方被新增后台驻留永久挂住。后台驻留只属于当前会话，不顺带增加开机启动或系统服务；重复启动、恢复已有会话与多实例策略按项目明确实现，不假称全局单例。

## 五、<span id="deployment-cleanup">安装位置与构建清理</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- 有构建／部署业务时分别核实目标安装位置与本地构建目录，不混用两边的卸载状态。支持两条路线的面板明确显示当前路线、载体名称与实际位置；默认值依据已确认项目规则，不将一个平台的目录或程序格式照搬到另一平台。
- 安装成功后自动清理仅在本单元部署、登记和核验全部成功后处理本轮准确产物，失败保留现场；卸载页签隐藏自动清理入口时保留同会话勾选，回安装恢复。构建目录仍被运行引用时清空／禁用该清理选择，避免清掉正在使用的 App。
- 独立“清除构建产物”用醒目的危险动作样式，位置与主操作区一致；仅在非空选、空闲且能核实目标安装位置、对象归属、登记和运行引用时可用。允许清理的路线必须有项目可验证的判据：已安装程序独立于待清构建输出，或未安装残留已证明没有登记／运行引用；不能仅凭一个“安全”布尔值放行。保留恢复依据，不按目录整片删源码、SDK、其它模块或共享缓存。
- 任务会话不能因更新或卸载最后一个承载组件而失去自身执行资源；采用独立快照或项目已有等价机制，保留完整日志和最终结果。源码更新、运行态更新、真实安装／清理分别报告，不为验收 UI 触发实际部署副作用。

## 六、<span id="maintenance-verification">交付与验收</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- **所有平台的 GUI 都必须同时交付“完整源码＋工程／构建或运行入口＋最终可运行成品”**，包括按 `【MacOS】🧩管理Finder扩展.app` 模板新增或改造的安装／卸载面板；不限于 MacOS。源码须覆盖界面、后台执行器、资源／翻译和必要配置，支持未来溯源、修改需求与重新生成成品。只有 App／EXE 等产物、只有启动壳、或只有源码而无成品，均不算交付完成。
- 编译型 GUI 保留实际工具链的工程或可复现构建入口；用户要求 Xcode 工程时须提供可编辑、编译、运行的原生 App target，不能用只打开旧 App 的空工程代替。解释型 GUI 同时交付独立可修改源码与含完整运行资源、启动入口及明确运行条件的分发运行包，不将源码目录／临时截图冒充成品，不将脚本启动包伪称原生 EXE。
- 每个 GUI 的源码、工程／构建入口和成品须在就近 README、上级导航及资产表一一对应，并记录实际构建来源、源码版本／摘要与验证状态；修改后同步生成和核验成品。找不到源码时先查本地仓库、原任务和可核对来源，保留既有产物，不能凭空拼一份相似界面冒充原源码，也不能仅凭签名或资源哈希声称旧二进制对应当前源码。按真实交付边界验证复制／改名及工程外工作目录启动，区分源码可用、构建通过、运行包可启动和目标平台实机验收。
- 标准源、独立包及内嵌副本同任务核对，保留原有业务差异。安装后的自带面板与源码仓分开盘点；只精准更新受影响资源并验证签名、未选模块和已有登记，不为更新界面结束用户正在执行的任务。旧进程不热加载新代码，不能把写了源码说成当前窗口已生效。
- 同任务更新项目资产表的入口、行为、默认值、持久化、生命周期、源码位置、差异与验证状态；就近说明同步取消过期的“只能点勾选框”或“忙时禁止关窗”等描述。需求规则只维护本附件，项目表记录实际实现，不在 Skill 堆源码摘要、测试次数或临时日志。

| 验收面 | 必须覆盖的可观察行为 |
| --- | --- |
| 行交互 | 复选框／标题／图标／普通状态／行空白单击一次切换；键盘与无障碍；链接独立动作；抬起出界、拖动、滚动、忙态及状态变化不误选 |
| 布局与偏好 | 最长翻译、藏文、窄／宽窗、各选择数量、拖动跨列后命中与对齐；主题／语言／布局切换保留状态 |
| 执行 | 成功、失败、无需卸载、未执行、权限阻断、无输出等待、取消／停止；按真实结果计数，独立计时与完整日志 |
| 后台 | 真实事件循环＋有界假 worker，所有关闭路径无任务中询问、隐藏后尾日志继续、完成仍后台、恢复原状态、空闲才真正释放；旧回调及状态竞态 |
| 日志 | 两主题／系统外观与高对比度、已有文本换色、对比度、长输出截断但文件完整、纯文本复制及手动滚动不抢尾 |
| 发布 | 包整体移动／改名及无关工作目录可用，标准／副本／安装资源一致；保全原有业务、权限和登记 |

验证使用隔离目录、假 worker 和可核对的实际控件／事件链，不为点击、验色或后台测试真实安装、卸载或清理。区分静态源码、合成边界、原生控件、目标系统实机、已安装后的人工交互；一端结果不能替代另一端，自动化受保护或无法定位时明确未验，不能推断通过。

样板定位：`JobsGenesis/OS@Extension` 的双端面板及 `项目相关报告/安装卸载管理面板需求资产盘点.md`。只用于理解已有方案，生成的新项目从自身实际位置定位资源，不在运行时依赖这套样板仓库。
