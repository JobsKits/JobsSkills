## 🔥 <span id="前言">前言</span>

> 本附件是系统右键功能的平台范围、独立工程与管理面板主规则。命中系统右键菜单或 `OS@Extension` 功能任务时必须读取；入口布局与 README 按 [OS@Extension 脚本布局](../jobs-markdown-docs/README规范-OS@Extension脚本布局.md)执行。

## 一、<span id="feature-contract">双端功能与安装边界</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

1、系统右键功能默认同时覆盖 [**macOS**](https://www.apple.com/macos/) 与 [**Windows**](https://www.microsoft.com/windows)。新增或修改功能时同时核对两端实现、管理清单、文档和验证；截图来自一端、当前运行环境只能验证一端，都不能自动把任务缩为单端。

2、用户明确指出的单端要求优先。先从当前对话与已确认项目约束识别例外，再决定需要实现的平台；不能为机械对齐重复增加系统已有且用户明确排除的入口。

3、每个功能使用独立子工程，具有自己的业务源码、功能标识、安装 / 卸载状态和管理入口，能够独立安装与卸载。完整功能目录可整体复制管理，共用基础设施不能携带其它功能业务，单个聚合开关不能冒充独立子工程。

4、两端各自提供管理面板，并同时包含安装 / 更新与卸载功能；平台总面板只管理本端功能集合。macOS 面板不安装或卸载 Windows 功能，Windows 面板不管理 macOS 功能；同一功能的单项入口仅管理本项。

5、管理面板默认空选，支持单项或多项操作，取消、关闭或空选不执行安装 / 卸载；点击操作按钮后在 GUI 内显示逐项状态及可复制日志。保留 `.command` / `.cmd` 公开入口及独立包能力，入口只唤起本端 GUI 并结束启动任务，已有工作终端会话保留。

6、交付前逐项核对“面板选项 → 功能 ID → 独立工程 → 菜单 / 宿主业务 → 安装产物与状态”，补齐上级入口和就近 README。两端隔离验证、真实安装及菜单交互分别报告；一端构建通过不能代表另一端已验收，普通测试不执行真实注册、卸载或重启文件管理器。

## 二、<span id="mac-file-create-exception">单端例外：新建文件</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

用户明确要求 macOS 增加“新建文件”，Windows 已由系统自带、无需再加时，只在 `OS@Extension/MacOS@Extension/JobsFileCreator` 实现独立功能 `file-create`，接入 macOS 管理面板。Windows 保留系统“新建”，不创建对应扩展；此例外只限定该功能，不改变其它系统右键任务的双端默认范围。
