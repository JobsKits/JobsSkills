## 🔥 <span id="前言">前言</span>

用于 Jobs 自维护的 [**MacOS**](https://www.apple.com/macos/) 交互脚本：当前会话临时使用黑底白字、白色光标与可读强调色，结束时按进入前的快照精确恢复。这里保存可直接复制的现行实现、用法和验证资源；通用脚本约定仍见[主规范](./SKILL.md#temporary-terminal-style)。

## 一、<span id="templates">选择现行范本</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

> 按目标入口原有解释器选取，保留模板内的监督与重入调用。

| 入口模式 | 复制资源 | 监督层调用 |
| --- | --- | --- |
| 标准 zsh 独立入口 | [zsh.guard.txt](./assets/terminal-style/zsh.guard.txt) | `/bin/zsh` |
| POSIX sh 独立入口 | [posix.guard.txt](./assets/terminal-style/posix.guard.txt) | `/bin/sh` |
| 明确使用 zsh `-f` 的独立入口 | [zsh-f.guard.txt](./assets/terminal-style/zsh-f.guard.txt) | `/bin/zsh -f` |

[资源清单](./assets/terminal-style/manifest.json)登记当前模板和测试文件的 SHA-256。三个文本文件都是完整保护块，包含唯一的 `jobs_terminal_style_bootstrap "$0" "$@"` 调用；它们是开发时复制的源码片段，生产脚本不得 `source` 或依赖 Skill 的路径、测试工具及安装位置。

## 二、<span id="integration">接入方式</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 先阅读目标入口及同类文件，核对所有权、解释器、参数、全局初始化、`trap`、日志和交互。只在用户授权的自维护范围内接入，不修改第三方、供应商或生成文件。
- 把所选资源从 `# >>> Jobs terminal style protection v1 >>>` 到对应结束标记的完整内容，复制到目标脚本的 shebang 与头部注释自述之后、原有执行逻辑之前。保留原有 shebang、参数顺序、工作目录、业务清理及末尾 `main "$@"`；`main()` 首步仍直接调用运行时内置自述。
- 保护监督层负责终端生命周期，业务在受保护子进程中执行一次；业务自己的 `trap` 继续负责原有清理。仅供 `source` 的模块不增加 bootstrap，不接管终端。已有末尾入口、原生 fork、录屏等专用信号监督或只读参数豁免的实现，保留其结构并局部合并共同行为，不能整块替换成标准重入版本。
- 核对解释器的预加载、选项及参数在重入后仍保持原意。无法保持原语义时沿用原解释器状态的已验证实现或使用纯文本；不擅自去掉 `-f`、改解释器、增加重复初始化或让业务执行两次。
- 生产运行只使用系统 Shell 与原生命令，不安装额外解释器。范本不承担业务依赖、自述确认或安装授权；这些流程继续由原入口编排。

## 三、<span id="color-protocol">颜色保存、核验与回退</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 修改前保存默认文字色、背景色、光标色和 ANSI 0～15 色，共 19 项。控制序列仅发往当前交互终端；日志与重定向输出保持纯文本。只修改已保存的颜色，不调整窗口透明度、背景图片、字体、默认主题、共享 Profile 或 Shell 启动文件。
- 每项查询最多实际发送 3 轮，每轮有界读取约 2 秒；按 BEL／ST 完整颜色帧解析、验证 RGB 并排除可识别旧帧。不能以增加等待代替重发，也不能把残缺帧拼接成另一个有效答复。
- 初始保存阶段严格拒绝键盘输入；保存不完整时尚未改色，保留原配色并使用纯文本。设置核验、独立回退与正常退出阶段，只在颜色帧边界识别 CR／LF、CSI／SS3 四向键及 CSI `1;2`～`1;8` 修饰方向键；每阶段独立共用最多 64 个控制单元，跨全部颜色项和重发累计。普通文本、未知或残缺转义、帧内按键、非法 RGB、冲突答复及超预算输入仍停止该阶段。
- 设置后必须读取并核对实际目标颜色。核验失败先报告具体颜色项和原因，再独立重新查询全部 19 项：仍等于本次目标值的项才撤回，已等于原值的项不重复写入，外部新配色保留。完整回退成功后以纯文本继续原业务一次；回退失答、归属冲突或输入无法验证时停止，保留恢复入口并返回失败。
- 正常退出先读取当前颜色，只恢复仍等于本次临时值的项。发生后续改色时保留新值，恢复其它可确认项，明确报告冲突并保留人工入口；无法可靠核验时不盲目使用旧快照覆盖。

## 四、<span id="lifecycle">终端与退出边界</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

- 非 TTY、`TERM` 为空或 `dumb`、`NO_COLOR`（含空值）、[**Sourcetree**](https://www.sourcetreeapp.com/)、既有纯文本模式及中转环境不盲发改色序列。未知终端必须按实际能力降级，不能仅凭 `TERM=xterm-256color` 宣称支持。
- 只控制脚本实际连接的前台 TTY，不操作“最前窗口”。同一 TTY 嵌套复用仍有效的保护所有者，由外层恢复；不同会话分别处理。保留原有业务退出码，配色恢复失败不能伪报成功。
- 正常退出、业务失败和可捕获的 HUP／INT／TERM 均执行恢复，并还原输入回显、规范模式、VMIN／VTIME。对需要在信号后继续封尾或询问的业务，保留其专用监督策略并单独验证。
- `SIGKILL`、终端崩溃及断电无法保证自动恢复。使用启动时打印的 `restore.sh` 路径，在原 TTY 运行；该入口要求精确输入 `YES`，会覆盖该终端当前配色，只有明确接受覆盖时才执行。不得用重置整个终端或清空用户配置代替精确恢复。
- 颜色协议与键盘输入共用输入流，存在有界探测与输入竞争；不承诺所有中转器、关闭窗口场景或自定义透明效果都可完整恢复。真实终端验收与独立伪终端结果分别说明。

## 五、<span id="validation">验证资源与用法</span> <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a>

[70 场景查询驱动](./assets/terminal-style/tests/terminal_query_retry_tests.py/README.md)保留完整 bootstrap／reexec，覆盖查询重发、分片、合法控制键、阶段预算、核验回退、冲突、真实业务次数与退出码。[17 场景生命周期驱动](./assets/terminal-style/tests/terminal_style_pty_tests.py/README.md)覆盖正常／失败、信号、键盘、嵌套、纯文本与恢复失败。两者仅依赖已有 [**Python**](https://www.python.org) 标准库，在独立 PTY 使用假业务和模拟颜色；这是开发验证依赖，不能引入生产运行流程。

默认从驱动自身位置定位随包的 `zsh.guard.txt`，与当前工作目录无关。在本 Skill 目录运行：

```shell
python3 ./assets/terminal-style/tests/terminal_query_retry_tests.py/terminal_query_retry_tests.py --yes
python3 ./assets/terminal-style/tests/terminal_style_pty_tests.py/terminal_style_pty_tests.py --yes
```

针对接入后的实际入口显式传入 `--source`；驱动只提取保护块，不执行该入口业务。查询驱动可用重复的 `--case` 做局部验证：

```shell
python3 ./assets/terminal-style/tests/terminal_query_retry_tests.py/terminal_query_retry_tests.py --yes \
  --source "待验证的独立入口.command" \
  --case applied-consecutive-keys \
  --case applied-later-color-rollback
```

- 输出默认使用新的临时目录；指定 `--output` 时也必须给尚不存在的结果目录，保留失败现场。核对完整输入模式、19 项原色、业务次数、退出码、恢复文件和纯文本标志。
- 按实际解释器分别执行 `zsh -n` 或 `sh -n`，并检查块外业务、已有改动、各变体语义和授权范围内同源副本；语法检查不能替代实际切换与还原。
- 在独立真实终端会话核对自定义浅／深背景、强调色和逐次复位，覆盖正常、失败、可捕获中断、嵌套与不同会话；只执行展示及退出控制，不为验色运行安装、删除、部署或其它真实业务。
