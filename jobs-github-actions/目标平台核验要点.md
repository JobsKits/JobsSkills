## 🔥 <span id="前言">前言</span>

> [主规范](./SKILL.md)要求命中原生或平台差异时读取相关部分。这里只列影响判断的核验点，不固定各工程的版本、runner、测试数量或实现方案；版本以本次配置和官方资料为准。

## <span id="jobs-toc-heading-2" data-jobs-toc="v2">一、跨平台共有边界 <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

- 以实际 shell 和运行时执行，核对参数引用、空格／中文／特殊字符路径、工作目录、大小写敏感、换行、执行位和符号链接。源文件编码、文件读写编码、终端代码页和进程 stdin／stdout／stderr 协议分别核对；一个 UTF-8 设置不能证明整条链正确。
- 所需命令、SDK、系统组件、服务与端点明确准备，缓存只作加速，不能成为冷启动成功的前提。凭据／外设／GUI 会话缺失时标明边界，不把假命令、假设备或编译通过写成真实操作验收。
- 子进程失败、预期非零、取消、超时、断管道和清理须保留原始结果；只回收本次拥有的进程和资源，恢复确实改动的环境，不能以清理覆盖原始异常。归档夹具使用正确的成员路径、字节和元数据，不修改安全校验去接受错误夹具。
- 修改复用 workflow、复合 action 或共享执行器时核对调用者的参数、secret、权限、输出及制品契约；矩阵变量、包名与路径须在各维度成立。

## <span id="jobs-toc-heading-3" data-jobs-toc="v2">二、[**Windows**](https://learn.microsoft.com/windows/) 与 [**PowerShell**](https://learn.microsoft.com/powershell/) <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

- `powershell` 与 `pwsh` 是不同执行目标；Windows PowerShell 5.1／.NET Framework 与 PowerShell 7／现代 .NET 的语法、API、编码及子进程行为不能互相代验。按实际目标解析并运行，涉及旧引擎时核对非 ASCII 源码的编码／BOM。
- Actions 内置 PowerShell 包装包含错误偏好及末尾 `$LASTEXITCODE` 检查，参照 [官方 shell 语义](https://docs.github.com/en/actions/reference/workflows-and-actions/workflow-syntax#jobsjob_idstepsshell)。负向原生命令可留下非零状态；验证测试进程本身的退出码及聚合器逐项失败传递，不用统一重置状态掩盖失败。
- 原生命令管道、CMD／OEM、TTY 交互和中文路径分别验证真实字节与结果。交互工具不能仅用无 TTY mock 验收；环境变量“缺失／空值／有值”、父子进程环境隔离和恢复按目标运行时核验。
- Win32、窗口控件／字体尺寸、注册表、文件身份、桌面会话与架构相关测试须有真实目标证据；托管 runner 非交互测试不证明 Explorer 菜单、ARM 桌面或真实 SDK／设备业务通过。平台条件跳过须出现在交付说明中。

## <span id="jobs-toc-heading-4" data-jobs-toc="v2">三、[**Linux**](https://www.kernel.org/) 与 [**MacOS**](https://www.apple.com/macos/) <a href="#前言" style="font-size:17px; color:green;"><b>🔼</b></a> <a href="#🔚" style="font-size:17px; color:green;"><b>🔽</b></a></span><!-- jobs-toc:heading-end -->

- 不以本机默认 shell 代替配置中的 `bash`／`sh`／`zsh`；自定义 shell 参数也会改变失败传播。核对管道与日志工具后的退出码、可执行位、大小写和系统工具参数差异。
- GNU／BSD 工具、系统库、动态库路径及包管理器位置按 runner 实际情况处理，不依赖个人登录配置或交互式初始化。无图形会话、权限或硬件时不冒称桌面／设备验收。
- [**Xcode**](https://developer.apple.com/xcode)／Apple SDK、目标架构、模拟器运行时、签名与制品导出分别核对；构建／模拟器通过不外推真机、签名发布或商店交付。证书等敏感信息仅使用现有授权机制，不写入日志或仓库。
